# Петр Фролов — портфолио

Сайт-воронка графического дизайнера: карточки и обложки для WB и Ozon, превью YouTube.

Опубликован через GitHub Pages: https://molluskin.github.io/frolovpetr.github.io/

## Структура

- `index.html` — главная: знакомство, цифры, кейс, примеры, цены, контакт.
- `more.html` — «Ещё работы»: печать, упаковка, сайты, логотипы.
- `style.css`, `app.js` — общие стили и скрипты.
- `img/`, `video/`, `fonts/`, `portfolio.pdf` — материалы.

## Что дописать вручную

- **Отзывы:** в `index.html` есть закомментированный блок `#reviews`. Добавьте скриншоты в `img/reviews/` и раскомментируйте.
- **Яндекс.Метрика:** вставьте код счётчика в `<head>` и перед ним `<script>window.YM_ID=НОМЕР;</script>`. Цели: `tg_hero`, `tg_header`, `tg_price_1`, `tg_price_2`, `tg_price_3`, `tg_youtube`, `tg_final`.
