# Пётр Фролов — портфолио

Сайт-воронка графического дизайнера: карточки и обложки для WB и Ozon, превью YouTube.

Опубликован через GitHub Pages: https://frolovpeter.github.io/portfolio_design/

## Структура

- `index.html` — главная: первый экран со стеклом и карточками, цифры, карусель работ, кейс «Было и стало», цены, обо мне, контакт.
- `more.html` — «Ещё работы»: печать, упаковка, сайт, логотипы. Шапка на обеих страницах одинаковая.
- `style.css`, `app.js` — общие стили и скрипты (система «Стекло»: Inter Tight + Caveat, шрифты лежат в `fonts/`).
- `img/hero/` — карточки первого экрана; `img/w/` — уменьшенные картинки карусели; `img/mp/`, `img/yt/` — полные версии; `img/ba/` — пары для сравнения.
- `video/`, `portfolio.pdf` — материалы.

## Как добавить работу

- В карусель: уменьшенная копия в `img/w/*.webp` (до 1100 px), полная рядом, строка в массиве `CATS` в `app.js`.
- В сравнение «Было и стало»: пара картинок и строка в массиве `LIST` в `app.js`.
- Первый экран: картинка в `img/hero/` и позиция в `DESK` / `MOB` в `app.js`.

## Что дописать вручную

- **Отзывы:** в `index.html` есть закомментированный блок `#reviews`. Добавьте скриншоты в `img/reviews/` и раскомментируйте.
- **Яндекс.Метрика:** счётчик стоит в `<head>` обеих страниц. Цели: `tg_hero`, `tg_header`, `tg_price_1`, `tg_price_2`, `tg_price_3`, `tg_youtube`, `tg_final`.
